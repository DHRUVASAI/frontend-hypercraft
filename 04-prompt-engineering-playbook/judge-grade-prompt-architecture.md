# Judge-Grade Prompt Architecture (When the Prompt Text Itself Is Scored)

1. **Concrete User & Acoustic Grounding:** Specify exact user constraints (screenless feature phones, farm/market noise, regional dialects & authentic code-mixed utterances).
2. **Two-Builder Determinism:** Lock fixed panel layouts, exact JSON profile schema, and a strict finite state machine (`IDLE -> GREETING -> SIX_CORE_FACTS -> NEAR_MISS -> HANDOFF -> CALLBACK`) so two independent builders produce nearly identical prototypes.
3. **Measurable Failure Ladders & Active Guardrails:** Specify quantitative triggers (`confidence < 0.70`), a non-trapping 3-step voice recovery ladder routing to `verify_at_visit`, and immediate `[REDACTED]` overwriting on sensitive ID recital.
4. **Built-In Fault-Test Bar:** Embed a 4-button fault simulator right in the prototype spec so judges can verify noise, code-mixing, misheard input, and privacy redaction in 10 seconds.
5. **Cross-Round Consistency & 3-Metric Word-Count Audit:** Diff strictly against prior round submissions (exact question count, modality, handoff actors) and verify whitespace words, hyphen-aware words, and strict alphanumeric tokens are ALL under the portal cap.
